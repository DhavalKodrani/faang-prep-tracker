GitHub sync

Progress is stored in progress.json in your repo, so every device sees the same data. Reading works without a token; to save from this device, paste a token once.

How to create a safe token
  1. Open github.com → Fine-grained tokens → Generate.
  2. Repository access: Only select repositories → pick this repo only.
  3. Permissions → Repository → Contents: Read and write. Nothing else.
  4. Paste it here. It is saved only in this browser on this device.
